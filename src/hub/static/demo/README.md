# Demo media (optional)

When `HUB_READ_ONLY=true`, Week video / Week audio **do not call Veo/Lyria**.

If you place files here, the public demo can play them:

| File | Shown as |
|------|----------|
| `week_recap.mp4` | Week video |
| `week_theme.wav` or `week_theme.mp3` | Week audio |

Without these files the buttons stay hidden — better than a broken “generate” click for visitors.

Generate once on a private (writable) deploy, download the outputs, copy them here, redeploy.
